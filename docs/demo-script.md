# Demo script (1:58)

Recorded from the public replay at 1080p, narrated, captioned, no music, fictional names only. One continuous match clock stays visible. Every beat comes from the one Studio take the surfaces show (the README's "Which take is shown"); the recovery beat replays that take's own recordings in a terminal.

`make video-clips` records each on-screen beat as a silent 1080p clip of the public link into `runs/video/` (`surfaces/web/scripts/record_beats.mjs`); the Clip column names them. `make video` (`scripts/make_video.py`) speaks the Narration column with an Azure AI Speech voice, fits each picture to its beat, burns in the captions and writes `runs/video/proofline-demo.mp4`. Only the Application Insights trace is not in it.

Every beat but one replays from recordings with the clock running. The live question is asked on the public link while recording; if the API is down or capped, use the recorded Ambrel question instead ("Is Ambrel tired since minute 60?"), which gives the same answer from its recording. Every claim spoken in the video is one the scoreboard supports at recording time; the rules require the project to work as depicted.

**What the proof narration rests on** (held-out records in `eval/records/`): false premises turned away, Proofline 98.0% against the plain agent's 70.0% (the same at the first answer and after the follow-up); false claims per question, Proofline below the plain agent at the first answer and after the follow-up; every Proofline-against-single-agent interval reaches zero. "Turned away" is the record's word: not turning a premise away includes finding no cause, so it is not the same as accepting it. If a record changes before recording, rewrite the line from the new records.
